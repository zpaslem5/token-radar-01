A token launch radar: it reads a frozen DefiLlama snapshot of 758 protocols, ranks every pre-token protocol by an implied value priced from the live market's own category multiples, and renders a dark dashboard with a farm plan for each one.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input input/snapshot.json
```
